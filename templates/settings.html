Rodeo & Broadcast Setup

Shown throughout the app, on judges' devices, on the Announcer Screen, and baked into the XML exports for broadcast graphics.

Point vMix / Ross XPression at this folder. Three files are kept continuously up to date: whos_up.xml, round_leaderboard.xml, aggregate_leaderboard.xml.

Controls both leaderboard XML files two ways: the combined all_names / all_ranks / all_lastnames / all_scores fields (one line-broken field per column, for a one-box "who's on the board" graphic), and individual numbered fields — rank_1/name_1/lastname_1/score_1, rank_2/name_2/... and so on — for graphics software that can't use the line-broken fields or a repeating list at all. The numbered fields always exist at this count, blank past however many are actually on the board, so the file's structure never changes shape. If "All" is selected, the numbered fields still cap at 20 since a fixed set of tags needs an actual number either way.

Scoring Setup

Applies to every roughstock event. Each judge scores the rider and the stock separately (1-25, half points, 50 max per judge). With 2 judges, both totals are added together; with 4, all four are added together and divided by 2 -- either way it lands on the same 0-100 scale as a directly-typed judged score.

Appearance

A small set of pre-tested combinations rather than free-form color control (full customization was tried once and removed -- it made it too easy to end up with something hard to read). Each option is chosen to stay clearly distinct from the app's fixed red/green/gold used for errors, saved scores, and penalties, so a theme choice is never mistaken for one of those.

Wrap-Up & Records

One spreadsheet with the final, all-rounds-combined standings for every event -- handy once the rodeo's finished, for handing off to a committee or association, or just archiving. Anyone entered but without a scored run in an event (DNS, DQ, etc.) is listed separately under that event, rather than left off.

A backup is the entire rodeo -- every competitor, event, round, entry, score, judge submission, and setting -- saved as a single file. Good insurance against a corrupted install or swapping to a different computer mid-event, and an easy way to archive a finished rodeo.

Restoring is a full replace, not a merge -- whatever's currently in the app is fully swapped out for what's in the file. A safety copy of the current data is saved automatically first (in the app folder's backups subfolder) in case the wrong file gets picked by mistake.
